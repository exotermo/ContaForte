# Política de segurança

O ContaForte lida com dados financeiros, que tratamos como sensíveis.

## Reportando vulnerabilidades

**Não abra issues públicas para vulnerabilidades.** Use o recurso *Report a vulnerability* na aba Security do repositório no GitHub (private vulnerability reporting).

Tentamos responder em até 7 dias.

## Escopo

- Nunca commite segredos, tokens ou dados reais. Se isso acontecer, reporte para que as credenciais sejam rotacionadas.
- O projeto adota Zero Trust, com identidade e autorização para cada componente, inclusive dispositivos IoT.

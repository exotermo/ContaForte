# ADR-003 — Java é dono do domínio financeiro

**Status:** Aceito · **Data:** 2026-11-23

## Contexto
Evita dupla fonte de verdade. O Python recebe dados por contrato e devolve resultados.

## Decisão
O backend Java é a autoridade sobre transações, contas e regras de negócio.

## Consequências
Ver o [SDD](../../SDD/SDD_Personal_Financial_Copilot.md) para o detalhamento. Revisitar esta decisão exige um novo ADR que a substitua.

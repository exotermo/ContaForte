# ADR-005 — REST para a API do MVP

**Status:** Aceito · **Data:** 2026-11-23

## Contexto
Simplicidade e ferramentas maduras.

## Decisão
API pública REST em `/api/v1`, documentada com OpenAPI. GraphQL só se houver necessidade comprovada.

## Consequências
Ver o [SDD](../../SDD/SDD_Personal_Financial_Copilot.md) para o detalhamento. Revisitar esta decisão exige um novo ADR que a substitua.

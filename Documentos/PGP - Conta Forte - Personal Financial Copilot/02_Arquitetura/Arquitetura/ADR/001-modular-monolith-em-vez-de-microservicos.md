# ADR-001 — Modular Monolith em vez de Microservices

**Status:** Aceito · **Data:** 2026-11-23

## Contexto
Reduz complexidade operacional, latência e overhead de deploy para um projeto mantido por uma pessoa. Os módulos permitem extração futura.

## Decisão
Um único backend Java organizado em módulos com limites claros.

## Consequências
Ver o [SDD](../../SDD/SDD_Personal_Financial_Copilot.md) para o detalhamento. Revisitar esta decisão exige um novo ADR que a substitua.

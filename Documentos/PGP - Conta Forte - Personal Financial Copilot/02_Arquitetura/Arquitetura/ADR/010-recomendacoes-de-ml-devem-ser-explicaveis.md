# ADR-010 — Recomendações de ML devem ser explicáveis

**Status:** Aceito · **Data:** 2026-11-23

## Contexto
Confiança do usuário e auditabilidade.

## Decisão
Toda recomendação carrega evidências estruturadas. Um LLM, se usado, só redige o texto e nunca calcula.

## Consequências
Ver o [SDD](../../SDD/SDD_Personal_Financial_Copilot.md) para o detalhamento. Revisitar esta decisão exige um novo ADR que a substitua.
